# Image Processing Workbench

A small Python CLI for exploring classic image transformations with a reproducible, generated input. It demonstrates a clear separation between image operations, command-line handling, and artifact reporting.

## Features

- Generates its own synthetic RGB image; no personal image or downloaded dataset is needed.
- Creates grayscale, resized, translated, rotated, and Fourier low-pass variants.
- Builds a labeled contact sheet for quick visual comparison.
- Writes a JSON manifest with each PNG's operation, byte size, and SHA-256 hash.
- Refuses to replace files in a non-empty output directory.

## Quick start

Use Python 3.10 or newer in an isolated environment.

~~~powershell
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
image-workbench demo --output-dir outputs/demo
~~~

On macOS or Linux:

~~~bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
image-workbench demo --output-dir outputs/demo
~~~

If `outputs/demo` already contains files, choose another output path. Generated PNGs and the manifest stay under the requested output directory, which is ignored by Git.

## CLI options

~~~text
image-workbench demo --help
~~~

- `--output-dir`: new or empty directory for generated PNGs and `manifest.json`.
- `--size`: generated image width and height, from 128 to 1,024 pixels.
- `--seed`: seed used for reproducible shapes and colors.
- `--cutoff`: normalized radial cutoff for the Fourier low-pass operation.

## Project structure

~~~text
src/image_workbench/
   cli.py          # Argument parsing and user-facing messages
   demo.py         # Synthetic input and output artifact pipeline
   operations.py   # Independent image transformations
~~~

## Data and provenance

This is an AI-assisted standalone portfolio demonstration inspired by the general image-processing themes in a notebook supplied by Ghaya Fouad. It does not upload the notebook, reuse its saved outputs, or include local images, datasets, model weights, or personal information. The demo input is generated by the project. No model training or benchmark result is claimed.

The library calls follow the official [NumPy FFT reference](https://numpy.org/doc/stable/reference/routines.fft.html) and [Pillow Image reference](https://pillow.readthedocs.io/en/stable/reference/Image.html).

## Scope

This project is a local learning demo. It does not upload images, call external services, train a model, or provide a production image-processing service.
